# SainAir – Expert en Climatisation à Nice ❄️

[![Status](https://img.shields.io/badge/Status-Live-green.svg)](https://sainair.com/)
[![Location](https://img.shields.io/badge/Location-Nice,%20France-blue.svg)](https://sainair.com/contact.html)

**SainAir** est une plateforme professionnelle dédiée aux services de climatisation dans la région de Nice et ses environs (Cannes, Monaco, Antibes). Le site présente les services d'installation, de réparation et d'entretien de climatiseurs pour les particuliers et les professionnels.

---

## 🚀 Fonctionnalités Clés

- **Services Complets** : Présentation détaillée des prestations (Installation, Réparation, Entretien).
- **Design Réactif** : Navigation fluide sur desktop, tablette et mobile avec un menu "burger" personnalisé.
- **Optimisation SEO** : Utilisation de données structurées (JSON-LD) pour un meilleur référencement local.
- **Interface Intuitive** : Accès rapide aux devis et aux appels directs.
- **Galerie de Réalisations** : Showcase des projets récents (Villas, Bureaux, Commerces).

---

## 🛠️ Technologies Utilisées

- **Frontend** : HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Icônes** : Lucide Icons (intégrées via SVG).
- **Typographie** : Polices modernes pour une lisibilité optimale.
- **Images** : Photographies haute résolution sourcées via Unsplash.
